## Tech Stack
*   **Platform:** MIT Scratch
*   **Concepts Used:** Variables, loops, clones, strings, and mathematical operations (modulo).

## What This Code Does
The program takes a word entered by the user and converts it into an 8-bit binary sequence, displayed visually by "aliens" (sprites).
1.  It loops through every letter in the user's word.
2.  It finds the ASCII value of that letter.
3.  It uses a custom algorithm (using the `mod 2` mathematical operator) to convert the ASCII number into an 8-bit binary sequence.
4.  It spawns 8 clones to represent the bits, turning them "ON" (green) for 1s and "OFF" (black) for 0s.
